01 / CONVERSATIONAUDIO ↔ AUDIO

GPT Live

Conversation, in real time.

Listens to your voice and speaks back. Keeps the conversation flowing while handing supported tasks to Pixie’s tools.

gpt-live-1

Live audio travels over WebRTC. Pixie’s configuration uses the Marin voice and can delegate work to a Responses model. The native app captures and plays audio; the model inference happens in the cloud.

Reasons over delegated tasks and requested screen context. Chooses from Pixie’s available tools to inspect, explain, or act.

IN Instructions + contextOUT Answers + tool calls

gpt-6-luna

Configured as the Responses delegate. Tool calls carry structured arguments to native handlers. Screen requests can include a captured image; UI inspection provides app controls. Tool results return to the conversation.

03 / DICTATIONAUDIO → TEXT
∿∿∿⟶a thought

GPT Live Transcribe

Your voice, in writing.

Turns incoming speech into text for dictation. A dedicated transcription path, separate from Pixie’s spoken conversation.

IN Microphone audioOUT Transcript
Under the hood +
gpt-live-transcribe

The stream sends 24 kHz PCM audio to a transcription session configured for low delay. “Pixie” is supplied as a recognition hint. Uploaded audio uses a separate GPT-4o mini Transcribe path.

GPT-4.1 Nano

A little editorial precision.

Handles dictation formatting when a model is needed. Some straightforward formatting stays in Pixie’s own code.

IN Raw transcriptOUT Formatted text
Under the hood +
gpt-4.1-nano

The dictation formatter uses a bounded text response with store: false. A separate formatting endpoint is configured with GPT-4.1 mini. Formatting can still make mistakes; review important text before sending.

FIELD NOTES / THE SMALL PRINT, MADE READABLE
Did Pixie train these models? +

No. These are OpenAI models. Pixie supplies the native Mac app, prompts, tool integrations, routing, and the surrounding experience.

Where are the benchmarks and parameter counts? +

We’re showing the actual integration, not an estimated leaderboard. We haven’t published a standardized Pixie benchmark, and we don’t infer parameter counts for these models. The diagrams on this page are explanatory, not measurements.

Does every request use every model? +

No. Conversation and dictation have different paths. Voice can delegate reasoning or tool work. Dictation uses transcription, with formatting when needed. Pixie doesn’t run the whole ensemble for every sentence.

What happens when a model or tool fails? +

An inference result isn’t a guarantee that an action succeeded. Pixie’s tools return results or errors. Transcription also has an uploaded-audio path. Availability, network conditions, permissions, and the target app can affect the outcome.
